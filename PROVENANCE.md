Public starting point: https://github.com/AmbireTech/extension/pull/35 . Upstream common: https://github.com/AmbireTech/ambire-common . Source revisions are immutable pins; branch tips may advance.

`harness/build.mjs` bundles original TypeScript sources and their actual imported helper implementations through esbuild. It does not replace status algorithms or use stale upstream dist output. `harness/build-provenance.json` is generated during reproduction and lists its bundled input paths and external imports. The published `sources.json` records the immutable upstream pins, proposed patch hashes and resulting changed-file hashes; a complete historical input-file hash manifest is not published here. Test reports record bundle hashes; different directory locations may change source annotations and bundle hashes on reproduction.

Fixtures were authored locally against the real submitted-operation shape and provider boundary. Synthetic account and recipient addresses, fixed transaction/block hashes, zero-value calls and a 21,000 gas receipt are artificial. They are not real user records or chain observations. Controlled receipt status 1 means success; status 0 means revert; null and transport errors remain unresolved. Delays are generated with local timers.

`controller-fixture.mjs` supplies storage, account, selected account, provider-controller, network, portfolio and safe collaborators. It invokes actual ActivityController methods, with real status classification, filtering, event emission and storage sequencing. Controller timing cases prepopulate `balanceChanges: []` to isolate activity status lookups. The HTTP runner leaves balance changes undefined and counts the upstream background backfill request too.

The HTTP runner returns JSON-RPC wire receipts from a loopback server and uses the upstream `getRpcProvider` factory unchanged. It observes formatted TransactionReceipt values returned to ActivityController. Its provider-controller collaborator is controlled; it does not instantiate the full app's ProvidersController, route Tor/Nym/Colibri/anon-rpc traffic, or run browser UI.

Generated using Node v20.11.1 on macOS arm64. Runtime dependency pins: ethers 6.16.0, viem 2.45.2, tldts 7.0.17, uuid 9.0.0, and idb 8.0.3 for the current source. esbuild 0.28.1; TypeScript 5.9.3; Prettier 3.3.3. Exact dependency resolution is in package-lock.json. Dependencies were chosen from the inspected source locks where applicable, not installed as arbitrary latest versions.

Commands and expected inputs are in README.md. Baseline output is generated by actually executing each immutable upstream implementation; it is not a hand-written golden status algorithm. The report generator compares recorded outcomes with the scoped consumer contract. Intentional differences are enumerated in DISCREPANCIES.md. This establishes partial local contract coverage, not full wallet or protocol conformance.

No entire upstream source tree is redistributed. The package contains original fixtures, runner code, measured outputs, proposed diffs and a pinned-source fetcher. Upstream repository licensing is not inferred from the absence of a license file in the inspected roots. Adoption and any license for original contributions should be agreed with the repository owner.
